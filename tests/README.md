# Testing

This folder provides the main integration test infrastructure of kirad.
You can run emulation tests and even collect OpenTelemetry data using [Jaeger](jaeger/)
or any other OpenTelemetry collector.

A rudimentary Wireshark CBOR bisector is provided in [`./wireshark/`](wireshark/).

## Running Tests

For further information on how to run the Python tests and use the interactive `nesttest`
console read the dedicated project [`README.md`](kira-test/README.md) of [kira-test](kira-test/).
